# Ficha de Aplicação — Método Inquebrável — Nível I

## Aula 19 — Fechamento: conduzir o próximo passo

### Objetivo
Conduzir a conversa a uma decisão ou próximo passo claro, sem pressionar o cliente.

### Aplicação prática
Crie uma conversa comercial real ou simulada após a apresentação da solução.

**1. Confirmar a avaliação**
Escreva uma pergunta simples para verificar se a proposta faz sentido para o cliente.

**2. Esclarecer dúvidas**
Escreva uma pergunta para descobrir se há algum ponto pendente.

**3. Conduzir o próximo passo**
Escreva uma pergunta clara sobre como o cliente deseja prosseguir, sem presumir que já decidiu comprar.

**4. Respeitar uma recusa**
Escreva uma resposta profissional para o caso de o cliente não querer avançar.

### Entrega
Apresente o diálogo com três possíveis caminhos:
- O cliente quer avançar.
- O cliente precisa esclarecer algo ou de tempo para avaliar.
- O cliente decide não continuar.

Para cada caminho, indique o próximo passo apropriado e as condições que ainda precisam ser confirmadas.

### Lista de verificação
- [ ] As perguntas são claras e respeitosas.
- [ ] Dei espaço para o cliente responder.
- [ ] Não tratei cordialidade como confirmação de compra.
- [ ] Não prometi prazo, disponibilidade ou condição sem verificar.
- [ ] Respeitei a decisão negativa sem exigir justificativa.

### Reflexão
Estou ajudando o cliente a tomar uma decisão clara ou pressionando por um “sim”?

### Orientação
Use uma situação real ou simulada. Identifique os exemplos fictícios e não registre uma venda ou compromisso que não tenha sido confirmado.
