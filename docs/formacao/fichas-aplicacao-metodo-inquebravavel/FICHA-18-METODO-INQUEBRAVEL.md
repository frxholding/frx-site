# Ficha de Aplicação — Método Inquebrável — Nível I

## Aula 18 — Objeções: ouvir, validar e responder

### Objetivo
Compreender a preocupação apresentada antes de responder, mantendo respeito, clareza e honestidade.

### Aplicação prática
Escolha uma objeção comercial, como “Está caro”, “Preciso pensar” ou uma dúvida sobre adequação.

**1. Ouvir**
Registre a objeção tal como aparece na situação real ou simulada. Escreva uma frase que permita à pessoa concluir sua explicação.

**2. Validar**
Redija uma frase que reconheça a preocupação sem discutir nem presumir que você já entendeu a causa.

**3. Esclarecer**
Formule uma pergunta respeitosa para descobrir o que a pessoa quer dizer ou qual informação precisa.

**4. Responder**
Escreva uma resposta pertinente às informações disponíveis. Se precisar verificar preço, prazo, disponibilidade, condição ou característica, registre isso em vez de inventar uma resposta.

### Entrega
Monte um diálogo curto com as etapas ouvir → validar → esclarecer → responder.

### Lista de verificação
- [ ] Não interrompi nem respondi antes de compreender.
- [ ] Reconheci a preocupação sem confronto.
- [ ] Fiz uma pergunta para esclarecer a dúvida.
- [ ] Não inventei dados, descontos ou promessas.
- [ ] Respeitei a possibilidade de a solução não ser adequada.
- [ ] Se faltou informação, deixei claro o que precisa ser verificado.

### Reflexão
Procuro compreender a objeção antes de responder ou reajo imediatamente tentando convencer?

### Orientação
A atividade pode usar uma situação real ou simulada. Identifique os exemplos fictícios e não apresente informações não verificadas como fatos.
