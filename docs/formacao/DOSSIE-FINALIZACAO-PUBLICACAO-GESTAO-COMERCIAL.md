Este documento consolida os requisitos necessários para transformar a formação Gestão Comercial, já estruturada pedagogicamente, em produto comercializável e certificável pela FRX.

## 5. O que pode avançar independentemente do áudio

Podem ser preparados desde já:

- configuração da estrutura do produto na plataforma;
- organização dos cinco níveis;
- cadastro das 37 aulas;
- associação preliminar dos materiais escritos;
- cadastro das atividades;
- cadastro das avaliações;
- preparação do projeto integrador;
- preparação das regras de conclusão;
- preparação da página comercial;
- preparação dos textos institucionais;
- organização dos materiais para publicação.

Nenhum desses itens deve receber duração ou carga horária oficial antes da conferência audiovisual.

## 6. Critérios institucionais — proposta

A proposta atualmente registrada sugere:

- aproveitamento final mínimo de 70%;
- atividades de aplicação: 20%;
- avaliação objetiva: 25%;
- estudos de caso: 20%;
- Caso Integrador Final: 15%;
- Projeto Integrador: 20%;
- mínimo sugerido de 60% no Projeto Integrador;
- uma oportunidade de recuperação.

**Status:** proposta, não regra oficial.

## 7. Carga horária

A carga horária oficial permanece em aberto.

Não calcular a carga horária pela simples soma dos áudios.

O cálculo deverá considerar o percurso efetivo do aluno, incluindo, conforme a metodologia definitiva:

- audiovisual;
- leitura;
- atividades;
- estudos de caso;
- avaliações;
- projeto integrador;
- demais tarefas obrigatórias.

## 8. Certificação

A emissão do certificado deverá depender da regra institucional finalmente aprovada pela FRX.

Antes da publicação, devem estar definidos:

- denominação da formação;
- carga horária;
- requisitos de conclusão;
- aproveitamento mínimo;
- recuperação;
- exigência do Projeto Integrador;
- dados que constarão no certificado.

## 9. Jornada do aluno

A jornada final deverá funcionar nesta sequência:

**Conhecer → Comprar/Matrícula → Acessar → Estudar → Aplicar → Avaliar → Concluir → Certificar.**

O teste de publicação deverá reproduzir essa jornada como se fosse um aluno real.

## 10. Gate final de publicação

A formação somente deve ser considerada pronta para publicação quando todos os itens abaixo estiverem confirmados:

- [ ] estrutura dos cinco níveis cadastrada;
- [ ] 37 aulas cadastradas;
- [ ] materiais vinculados;
- [ ] audiovisual conferido;
- [ ] duração das aulas registrada;
- [ ] divergências corrigidas ou aceitas;
- [ ] atividades vinculadas;
- [ ] avaliações configuradas;
- [ ] Projeto Integrador configurado;
- [ ] critérios institucionais aprovados;
- [ ] carga horária definida;
- [ ] certificado configurado;
- [ ] página comercial revisada;
- [ ] preço e condições comerciais definidos;
- [ ] acesso do aluno testado;
- [ ] progresso testado;
- [ ] avaliação testada;
- [ ] conclusão testada;
- [ ] emissão do certificado testada;
- [ ] jornada completa testada em ambiente de produção ou homologação.

## 11. Regra de qualidade

Não considerar a formação pronta apenas porque os arquivos existem.

O produto somente está pronto quando o aluno consegue completar a jornada inteira sem intervenção manual indevida.
