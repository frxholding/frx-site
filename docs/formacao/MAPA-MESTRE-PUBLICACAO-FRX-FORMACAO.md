## 3. Bloqueios que ainda impedem declarar os produtos como finalizados

### 3.1 Audiovisual

Não utilizar o nome do arquivo como prova de correspondência com uma aula.

É necessário:

1. identificar o conteúdo efetivamente tratado em cada arquivo;
2. mapear arquivo → nível → aula;
3. registrar duração real;
4. identificar arquivos duplicados ou incorretos;
5. confirmar se existe cobertura audiovisual suficiente para a estrutura pedagógica;
6. somente depois registrar duração oficial das aulas.

### 3.2 Carga horária

A carga horária oficial não deve ser obtida apenas pela soma dos áudios.

Deve considerar o percurso efetivo do aluno, conforme a metodologia institucional final, incluindo conteúdo audiovisual, leitura, atividades, avaliações e projeto quando aplicável.

### 3.3 Avaliação e conclusão

Antes da publicação definitiva, cada formação precisa ter regra institucional explícita para:

- aproveitamento mínimo;
- atividades obrigatórias;
- avaliação;
- recuperação;
- projeto/caso integrador, quando aplicável;
- condição de conclusão;
- certificação.

### 3.4 Certificado

Definir, por produto:

- denominação;
- carga horária;
- requisitos;
- aproveitamento;
- dados exibidos;
- regra de emissão.

## 4. Regra comercial

Enquanto os gates acima não estiverem concluídos, as páginas devem comunicar a estrutura e a proposta da formação sem apresentar como definitivos dados ainda não aprovados.

Evitar promessas de resultado garantido.

Não publicar carga horária, nota mínima, critérios de aprovação ou certificação como fatos oficiais antes da aprovação institucional.

## 5. Ordem recomendada de fechamento

**1. Audiovisual → 2. Carga horária → 3. Critérios institucionais → 4. Certificação → 5. Configuração da plataforma → 6. Teste completo do aluno → 7. Publicação definitiva.**

## 6. Critério de pronto

Uma formação somente deve ser marcada como **PRONTA PARA PUBLICAÇÃO** quando um aluno conseguir realizar a jornada:

**Conhecer → Comprar/Matrícula → Acessar → Estudar → Aplicar → Avaliar → Concluir → Certificar**

sem depender de intervenção manual indevida.
