# Validação Documental — Gestão Comercial na Prática

**FRX Formação Profissional**

## Critério

Esta validação considera exclusivamente a estrutura e o conteúdo das cinco apostilas-base utilizados na construção da formação.

Ela verifica:
- correspondência da aula com o capítulo de origem;
- sequência pedagógica;
- preservação do tema central;
- existência de atividade coerente;
- separação entre conteúdo escrito e audiovisual.

A validação **não substitui** a conferência do áudio.

## Resultado geral

**37 de 37 aulas** possuem correspondência documental com os capítulos definidos a partir das cinco apostilas-base.

### O que esta validação confirma

- a estrutura de 5 níveis está coerente;
- a sequência das aulas está coerente;
- os títulos das aulas correspondem aos capítulos trabalhados;
- as atividades foram construídas para aplicação dos respectivos temas;
- o Projeto Integrador percorre os cinco níveis.

### O que esta validação NÃO confirma

Ela não comprova que:
- o áudio aborda exatamente o mesmo conteúdo;
- o áudio cobre todas as aulas;
- a duração atual é suficiente para cada unidade;
- os slides reproduzem integralmente o áudio;
- a carga horária oficial já esteja definida.

Esses pontos permanecem separados para não transformar uma inferência em validação.
